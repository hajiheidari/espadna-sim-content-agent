# Asset provenance

Six original background plates generated with the built-in ImageGen tool on 2026-10-25. No API key, external paid service, stock-photo purchase or source reference crop was used. The customer-supplied contact sheet guided composition planning; it is not included in the repository. All Persian text, phone numbers, icons, buttons and the geometric retailer monogram are separate code-native layers.

Font: Vazirmatn v33.003, Regular and Bold, from https://github.com/rastikerdar/vazirmatn/tree/v33.003. Font license: SIL Open Font License 1.1; bundled OFL.txt is preserved. No font modifications were made.

Scenes are decorative and have no geographic relation to phone prefixes. The skyline is not used as evidence of service area. Gold objects and charts carry no financial promise. No image asset has a phone number or customer data. The monogram is a vector interpretation, not an original master logo file.
